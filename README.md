# Mission List

This mod adds a new Mission List to the mission select screen which shows all the missions available in one single menu
so you can find the missions you want at a quick glance instead of struggling when rotating the 3D planets.

The mod is highly configurable, so I recommend using [Sparroh](https://thunderstore.io/c/mycopunk/p/Sparroh/)'s [ModSettingsMenu](https://thunderstore.io/c/mycopunk/p/Sparroh/ModSettingsMenu/) to tweak the settings without having
to restart the game every time.

I'll *probably*™ add more features later on.

## Features

- 🧭 **Better Mission Discovery**: Browse all available missions in one convenient menu
- 🗂️ **Custom Sorting**: Sort missions by Mission Type, Biome, or Modifier Count
- 🔬 **Mission Visibility Controls**: Hide/show PTO, Incursion, Ouroboros, weeklies, and more
- 🎨 **Biome-Based Outline Colors**: Optionally color mission outlines based on their biome

## Configurations

| Setting                           | Default Value | Description                                                              |
|-----------------------------------|---------------|--------------------------------------------------------------------------|
| Sorting Method                    | `MissionType` | Determines how missions are sorted in the Mission List.                  |
| Is Open By Default                | `false`       | Automatically opens the Mission List when interacting with the terminal. |
| Biome-Based Outline Color         | `false`       | Colors mission outlines based on their biome color.                      |
| Paid Time Off                     | `true`        | Includes Paid Time Off in the Mission List.                              |
| Incursion                         | `true`        | Includes Incursion in the Mission List.                                  |
| Ouroboros                         | `false`       | Includes Ouroboros in the Mission List.                                  |
| Ouroboros Blitz                   | `false`       | Includes Ouroboros Blitz in the Mission List.                            |
| Oxythane Breach: Escalation       | `false`       | Includes Oxythane Breach: Escalation in the Mission List.                |
| Completed Weeklies                | `Vanilla`     | How the completed weekly missions are shown.                             |
| Include Extra Permanent Locations | `false`       | Includes missions from the "Permanent Locations" tab.                    |
| Include Replay Missions           | `false`       | Includes missions from the "Replay Missions" tab.                        |
